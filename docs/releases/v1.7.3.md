## Alethe 1.7.3

A fix for updating from inside the app.

### 🔧 "Update now" works again

- **Updates download, install and restart from the prompt.** Choosing **Update now** used to fail with
  "download not allowed by ACL", because the app lacked the permission to download and install an
  update in two steps. It now has it.

### ⚠️ One manual step if you are on 1.7.2 or earlier

- Those versions still carry the old permission, so they cannot update themselves to this one. Install
  1.7.3 once from the installer:
  [`Alethe-Setup.exe`](https://github.com/Vnxcarvalho/Alethe-2.0/releases/latest/download/Alethe-Setup.exe).
  Your projects, layouts and sessions are kept. From 1.7.3 on, the in-app update works.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Alethe-2.0/blob/main/docs/CHANGELOG.md).
