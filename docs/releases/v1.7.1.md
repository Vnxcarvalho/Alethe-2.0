## Alethe 1.7.1

A feature update on top of 1.7.0: agent teams, a richer plugin platform, orchestration playbooks
and a new app icon. Existing projects, layouts, sessions and themes carry over unchanged.

**Updating is optional.** If you already run Alethe 1.7.0, a prompt offers the update from inside the
app: choose **Update now** to download and install it, or **Later** to keep working. There is no need
to download the installer again.

---

### 🤝 Agent teams

- **Claude Code and Antigravity teams.** Open a lead plus one terminal per teammate, side by side.
  Antigravity teams coordinate through a `TEAM.md` file at the project root, and with project
  isolation on, each member gets its own worktree.
- **Built-in `tmux`.** Teams work without installing anything extra.

### 🔌 Plugins

- **Plugin API 3.** Plugins can follow every running terminal tab, including background ones.
- **Agent Voice.** A new plugin in the catalogue (Preferences → Plugins).

### 🧠 Orchestration and skills

- **Playbooks editor.** A new Playbooks page in Preferences shows every orchestration playbook.
- **Official skills** are always listed in the Skills window and can be installed into a project.

### 🗂️ Workspace

- **Minimize a terminal instead of deleting it.** The terminal header gets a minimize button.
- **Tutorials.** A new Tutorials page in Preferences plays videos of Alethe in real work.
- **New app icon: Carvalho.** Available in Preferences → Appearance, and the default for new
  profiles. Profiles that already picked an icon keep it.

### ☁️ Sync

- **Cloud sync merges instead of overwriting**, with MCP servers and skills kept per account and per
  project.

### ⬇️ Download

- Windows installer: [`Alethe-Setup.exe`](https://github.com/Vnxcarvalho/Alethe-2.0/releases/latest/download/Alethe-Setup.exe).
  This release ships for Windows only.

The complete list of changes is in [`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Alethe-2.0/blob/main/docs/CHANGELOG.md).
