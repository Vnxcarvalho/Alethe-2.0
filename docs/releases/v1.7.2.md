## Alethe 1.7.2

A small update that moves the update prompt to a more visible place.

**Updating is optional.** If you already run Alethe 1.7.1, a prompt offers this update from inside
the app: choose **Update now** to download and install it, or **Later** to keep working. There is no
need to download the installer again.

---

### 🔔 Update button in the title bar

- **A button right after your profile name.** When a newer version is available, the title bar shows
  a button with the new version number. It opens the same prompt, with **Later** and **Update now**.
  It replaces the chip that used to sit at the bottom of the sidebar.

### ⬇️ Download

- The Windows installer is now published automatically with every version, and the READMEs link to
  it: [`Alethe-Setup.exe`](https://github.com/Vnxcarvalho/Alethe-2.0/releases/latest/download/Alethe-Setup.exe).
  This release ships for Windows only.

The complete list of changes is in [`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Alethe-2.0/blob/main/docs/CHANGELOG.md).
