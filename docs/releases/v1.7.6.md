## Alethe 1.7.6

A maintenance release with no visible changes. It is published to verify that updating from inside the
app finishes and reopens Alethe by itself.

**Updating is optional.** If you run Alethe 1.7.5, a prompt offers this update from inside the app:
choose **Update now** to download and install it, or **Later** to keep working. The app should close,
install the update and open again on its own. There is no need to download the installer again.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Alethe-2.0/blob/main/docs/CHANGELOG.md).
