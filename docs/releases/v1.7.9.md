## Arcadia 1.7.9

Alethe is now **Arcadia**: a new name, a new logo and new installer artwork. Your projects, profiles and
settings stay where they are. If Alethe is installed, the installer removes it and installs Arcadia in its place.

If you pinned the old app to the taskbar, pin Arcadia again.

The logo is the pixel-art bust with the red blindfold, in the window, the taskbar, the installer and the
`.exe`. It is also the default profile picture. The Elite artwork icons are gone; the Elite colour themes stay.
A profile with its own photo keeps it.

**New: clone your GitHub repositories.** Sign in with GitHub from the Home ("clone from github") or from New
project, pick one of your repositories, including private and organization ones, and Arcadia clones it. Cloning
now brings the full history. The old cloud sign-in, which depended on a server that no longer exists, is hidden.

**Updating is optional.** If you run version 1.7.5 or later, a prompt offers this update from inside
the app: choose **Update now** to download and install it, or **Later** to keep working. If you run
1.7.4 or earlier, install this version once from the installer.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Arcadia/blob/main/docs/CHANGELOG.md).
